🎨 القاعدة بالألوان — Grammar 1: The first conditional

Look at these sentences. Which tense comes after "if"?انظر إلى الجمل. ما الزمن الذي يأتي بعد if؟

هل لاحظت؟ بعد if نستخدم المضارع البسيط (rains, don't hurry, is)، حتى لو كان المعنى في المستقبل. والـ will تأتي في النتيجة فقط.

NOW — الآن: we don't know
if it rains (condition) — الشرط
➜
we'll stay home (result) — النتيجة
⬅ PastFuture المستقبل ➡

النقطة الخضراء = الشرط (if + present simple). النقطة البنفسجية = النتيجة (will + base verb). كلاهما في المستقبل.

PartStructureExample
Condition 🟢If + present simpleIf it's sunny,
Result 🟣will / won't + base verbwe'll go to the beach.
Result firstwill + verb + if + present (no comma)We'll go to the beach if it's sunny.
Negative ❌If ... don't / doesn't, ... won'tIf it doesn't clear up, we won't go.
Question ❓What will you do if ...?What will you do if it rains?
💡 Rule: إذا بدأت الجملة بـ If نضع فاصلة بعد الشرط: If it rains, we'll stay home. وإذا بدأت بالنتيجة فلا فاصلة.
📝 Less sure? إذا لم تكن متأكدًا من النتيجة، استخدم might بدل will: If it rains, we might stay home. (ربما نبقى)

🔗 Grammar 2: if vs when

if = ربما يحدث 🤔when = متأكد أنه سيحدث ✅
If I see Ali, I'll tell him.
(لست متأكدًا أنني سأراه)		I'll call you when I get home.
(سأصل إلى البيت بالتأكيد)

وبعد when أيضًا نستخدم المضارع البسيط: when I get home، وليس when I will get ❌.

🚫 Grammar 3: unless = if ... not

Weنحن'll goسنذهبto the beachإلى الشاطئunlessإلا إذاit(الجو)rainsأمطرت

= We'll go to the beach if it doesn't rain.

⚠️ unless معناها منفي من نفسها. لا تضع بعدها نفيًا آخر: unless it doesn't rain ❌ → unless it rains ✅.

🔁 العربية مقابل الإنجليزية — Arabic vs English

العربية

إذاifأمطرتْrains (ماضٍ!)سنبقى'll stayفي البيتat home
سنذهب'll goإلا إذاunlessأمطرتْrains

العربية تستخدم الماضي بعد «إذا» (أمطرتْ، جاءَ)، مع أن المعنى في المستقبل.

English

Ifitrains,مضارع، لا ماضٍ ولا willwe'll stayat home.
We'll gounlessitrains.

الإنجليزية تستخدم المضارع البسيط بعد if.

✅ سهل عليك: «سـ / سوف» في النتيجة = will: «سـنبقى» = we'll stay. و«إلا إذا» = unless تمامًا! وترتيب الجملة مرن كما في العربية: الشرط أولًا أو النتيجة أولًا.
⚠️ صعب عليك (1): لأن المعنى مستقبل، يضع كثيرون will بعد if: If it will rain ❌. القاعدة: لا نستخدم will بعد if / when / unless. الصحيح: If it rains ✅.
⚠️ صعب عليك (2): بسبب «إذا أمطرتْ» قد تقول If it rained, we will stay ❌. صيغة الماضي بعد if لها معنى آخر (خيالي)، وسنتعلمها في الدرس 6.
⚠️ صعب عليك (3): «عندما» في العربية لا تفرّق بين المتأكد وغير المتأكد. في الإنجليزية: when = متأكد، if = ربما. لا تقل When I win the lottery... إلا إذا كنت متأكدًا 😄

👄 النطق: 'll و won't

في الكلام العادي، will تصبح 'll: صوت /l/ «غامق» في آخر الكلمة، واللسان يرتفع من الخلف قليلًا. لا تحذفه، لأن الجملة بدونه تصبح في المضارع!

بدون 'll (مضارع)مع 'll (مستقبل)
I call you. I'll call you. /aɪl/
We go. We'll go. /wiːl/
It rains. It'll rain. /ˈɪt.əl/

won't vs want — انتبه!

هاتان الكلمتان متشابهتان، لكن معناهما مختلف جدًا:

won't /woʊnt/ «وُونْت» = لنwant /wɑːnt/ «وَانْت» = يريد
I won't go. لن أذهب.I want to go. أريد أن أذهب.
💡 نصيحة: في won't الشفتان مستديرتان كما في «أُو». وفي want الفم مفتوح. استخدم زر 🐢 لتسمع الفرق.

📌 الخلاصة — Summary

  • احتمال حقيقي في المستقبل: If + present simple, will + base verb.
  • لا will بعد if / when / unless.
  • when = متأكد · if = ربما · unless = إلا إذا (if ... not).
  • غير متأكد من النتيجة؟ استخدم might: If it rains, we might stay home.
  • فاصلة بعد الشرط إذا بدأت الجملة بـ If.
  • انطق 'll بوضوح، وفرّق بين won't (لن) و want (يريد).
