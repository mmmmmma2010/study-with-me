past simple form — شكل الماضي
NOW — المعنى هنا: الآن
💭 If I had... I'd... (imaginary)
⬅ Past الماضيFuture المستقبل ➡

الشكل يشبه الماضي، لكن المعنى في الفقاعة 💭: موقف خيالي الآن أو في المستقبل.

PartStructureExample
Condition 💭If + past simpleIf I had time,
Resultwould / 'd + base verbI'd learn Japanese.
Negative ❌If ... didn't, ... wouldn'tIf I didn't have a job, I wouldn't be happy.
Question ❓What would you do if + past?Where would you live if you could choose?

💡 Rule: الفاصلة مثل الدرس 5: If I had money, I'd travel. و I'd travel if I had money. (بدون فاصلة).

👑 Grammar 2: If I were...

مع فعل be نستخدم were مع كل الضمائر، حتى مع I / he / she / it. هذا هو الشكل الرسمي والأفضل في الكتابة:

  • If I were rich, I'd help my family.
  • If my brother were here, he'd know the answer.
📝 ملاحظة: في الكلام غير الرسمي ستسمع أيضًا If I was rich...، وهذا مقبول في المحادثة. لكن في تعبير النصيحة نقول دائمًا If I were you.

🌳 First or second conditional? — «إذا» أم «لو»؟

flowchart TD A["Is the situation real and possible? / هل الموقف حقيقي وممكن؟"] -->|"Yes, it may happen / ممكن (إذا)"| B["First: If + present, will. If it rains, I'll stay home."] A -->|"No: imaginary or very unlikely / خيال أو بعيد (لو)"| C["Second: If + past, would. If I won the lottery, I'd travel."] C --> D["Advice: If I were you, I'd..."]

🔁 العربية مقابل الإنجليزية — Arabic vs English

العربية

لوifكنتُwere (ماضٍ)غنيًاrichلاشتريتُwould buyبيتًاa house

العربية: لو + ماضٍ، والنتيجة لـ + ماضٍ.

English

IfIwererich,Iwouldإجباري!buya house.

الإنجليزية: if + past، والنتيجة would + base verb (ليس ماضيًا).

✅ سهل عليك جدًا: العربية تفرّق بين «إذا» و«لو» كما تفرّق الإنجليزية بين الشرطية الأولى والثانية!
«إذا» (ممكن) = If + present, will · «لو» (خيال) = If + past, would.
وكما في العربية، نستخدم الماضي بعد «لو» مع أن المعنى عن الآن.
⚠️ صعب عليك (1): بسبب «لاشتريتُ» بالماضي قد تقول If I were rich, I bought a house ❌. النتيجة تحتاج would: I would buy ✅.
⚠️ صعب عليك (2): لا تضع would في الجزءين: If I would have money, I would travel ❌. القاعدة مثل الدرس 5: لا will / would بعد if.
⚠️ صعب عليك (3): لا تخلط الشرطيتين: If I had money, I will travel ❌. إما have ... will وإما had ... would.

👄 النطق: I'd و wouldn't

في الكلام العادي، would تصبح 'd: صوت /d/ صغير جدًا. لا تحذفه، لأن الجملة بدونه تصبح في المضارع!

بدون 'd (حقيقة الآن)مع 'd (خيال)
I buy a car. I'd buy a car. /aɪd/
We live by the sea. We'd live by the sea. /wiːd/
They help us. They'd help us. /ðeɪd/

would = wood — الحرف l صامت!

  • would /wʊd/ «وُد» (مثل wood)
  • wouldn't /ˈwʊd.ənt/ «وُدِنْت»
  • في السؤال تكون would ضعيفة: What would you do? /wət wəd jə duː/
💡 نصيحة: I'd قد تعني I would أو I had. انظر إلى الكلمة التالية: إذا جاء بعدها فعل في المصدر (I'd buy) فهي would.

👀 Model answer (77 words)

If I won a million dollars, I would do three things. First, I'd pay off my family's debts and buy my parents a new flat. Then I'd travel to Japan, because I've always wanted to see Kyoto. I'd also invest some money in a small coffee shop. I wouldn't quit my job, because I really enjoy it. If I were a millionaire, I'd give away part of the money to charity, too.

📌 الخلاصة — Summary

  • خيال أو احتمال بعيد الآن أو في المستقبل: If + past simple, would + base verb.
  • الشكل ماضٍ، لكن المعنى ليس عن الماضي.
  • «إذا» (ممكن) = if + present, will · «لو» (خيال) = if + past, would.
  • If I / he / she were... (و was مقبولة في الكلام غير الرسمي).
  • النصيحة: If I were you, I'd...
  • نتيجة ممكنة فقط: could / might بدل would.
  • انطق would «وُد»، ولا تحذف 'd في I'd.
