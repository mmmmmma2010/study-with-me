# Study With Me · ادرس معي

منصة تعليمية ساكنة (Static Frontend) تجمع ملفاتك الدراسية في واجهة واحدة أنيقة ومتجاوبة بدون قاعدة بيانات أو خادم خلفي، وجاهزة للنشر على **GitHub Pages**.

## المميزات
- **تنظيم تلقائي حسب المجلدات**: عرض المواد تحت أسماء مجلداتها (`System Design` و`English`).
- **متابعة التقدم محليًا**: حفظ الدروس المكتملة وآخر درس مفتوح في `localStorage`.
- **قارئ دروس مدمج**: التنقل بين الدروس (السابق / التالي) مع إمكانية فتح الدرس في صفحة مستقلة.
- **بحث وفلاتر فورية**: البحث بالعربية والإنجليزية والتصفية حسب القسم أو حالة الإكمال.
- **الوضع الفاتح والداكن**: متوافق تمامًا مع تصميم المواد الدراسية الأصلية.

## كيف تضيف مواد جديدة أو قسمًا جديدًا؟

### الطريقة 1: التحديث التلقائي (المُوصى بها)
1. ضع ملفات الـ `.html` الجديدة داخل مجلد القسم الحالي (مثل `System Design/` أو `English/`)، أو أنشئ مجلدًا جديدًا في المجلد الرئيسي (مثل `Algorithms/`).
2. شغّل السكربت التالي لتحديث `data/catalog.js` تلقائيًا:
   ```bash
   python3 scripts/sync_catalog.py
   ```
3. ارفع التغييرات إلى GitHub ليتم تحديث الموقع تلقائيًا.

### الطريقة 2: التعديل اليدوي
افتح ملف `data/catalog.js` وأضف عنصرًا جديدًا داخل مصفوفة `items` للقسم المطلوب، أو أضف كائن قسم جديد إلى `window.STUDY_CATALOG`.
